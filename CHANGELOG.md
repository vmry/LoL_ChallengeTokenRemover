# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-19

### Added

- One-click Windows batch launcher.
- Automatic LCU credential discovery from League Client process arguments.
- League Client lockfile fallback.
- Challenge token removal through the local challenge preferences endpoint.
- Windows PowerShell 5.1 and PowerShell 7+ compatibility.
- Structured exit codes and verbose diagnostic output.
- GitHub Actions validation with PSScriptAnalyzer.
- Repository documentation, contribution guidelines, security policy, issue template, pull request template, and code of conduct.
